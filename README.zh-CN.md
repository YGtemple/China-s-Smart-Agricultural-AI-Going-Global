# 中国智慧农业 AI 出海

关于中国农业 AI 产品走向海外市场的调研笔记。

<sub>Markdown · 调研笔记</sub>

---

## 覆盖什么

中国农业 AI 在哪些方面有出口优势，哪些没有。笔记从三个角度看：

- 哪些品类能跨市场通用，哪些受制于本地条件
- 不同目的地市场的监管与数据约束差异
- 技术能力和海外买家真正会掏钱买的东西之间的落差

## 说明

是笔记，不是结论——文档集还在增长，每节都标注了来源，方便之后复核。
